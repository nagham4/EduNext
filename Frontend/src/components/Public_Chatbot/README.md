# Reusable General Chatbot

قالب شات بوت جاهز للنقل لأي مشروع React.  
مخصص للأسئلة العامة من الزوار أو الطلاب عن الموقع: الهدف، التسجيل، تسجيل الدخول، الصفحات، أقسام الطالب، والخدمات المتوفرة.

## أين أعدل؟

كل التعديل الأساسي موجود في ملف واحد:

`generalChatbotService.js`

افتحه وعدل فقط الجزء الموجود في الأعلى باسم:

`EDIT_THIS_CONTENT`

داخله ستجد:

- `projectName`: اسم المشروع.
- `assistantTitle`: عنوان الشات بوت.
- `introMessage`: أول رسالة تظهر للمستخدم.
- `suggestions`: أزرار الأسئلة المقترحة.
- `siteSections`: الصفحات والأقسام والروابط التي يمكن السؤال عنها.
- `featureAnswers`: إجابات عامة عن هدف الموقع وخدماته.
- `siteKeywords`: كلمات تساعد الشات بوت يعرف أن السؤال عن الموقع.
- `outOfScopeKeywords`: مواضيع ممنوع يدخل فيها.
- `boundaryReply`: الرد لما السؤال يكون خارج نطاق الموقع.

## كيف أضيف صفحة طالب؟

داخل `siteSections` أضف عنصر بهذا الشكل:

```js
{
  key: 'student-dashboard',
  title: 'لوحة الطالب',
  route: '/student-dashboard',
  aliases: ['لوحة الطالب', 'صفحتي', 'dashboard الطالب'],
  answer: 'لوحة الطالب تعرض ملخص سريع عن حساب الطالب وتقدمه داخل الموقع.',
}
```

## كيف أضيف خدمة أو ميزة؟

داخل `featureAnswers` أضف:

```js
{
  aliases: ['درجاتي', 'علاماتي', 'النتائج'],
  answer: 'قسم النتائج يساعد الطالب يشوف أداءه أو علاماته إذا كان هذا القسم موجود في المشروع.',
}
```

## Prompt جاهز لكوبايلوت

انسخ هذا النص لكوبايلوت داخل المشروع الأصلي:

```text
افحص المشروع كامل، خصوصا الصفحة الرئيسية وكل صفحات الطالب والزائر.
بدي تجهز ReusableGeneralChatbot/generalChatbotService.js عن طريق تعديل EDIT_THIS_CONTENT فقط.

المطلوب:
1. استخرج الصفحات العامة وصفحات الطالب التي ممكن الزائر أو الطالب يسأل عنها.
2. أضف كل صفحة داخل siteSections مع route صحيح و aliases بالعربي والإنجليزي لو موجود.
3. أضف إجابات عامة داخل featureAnswers عن هدف الموقع، خدماته، شو بوفر للطالب، كيف يسجل، كيف يدخل، وكيف يستخدم الصفحات المهمة.
4. أضف كلمات بحث مهمة داخل siteKeywords حتى يتعرف الشات بوت على أسئلة الموقع.
5. لا تضيف صفحات أدمن أو تفاصيل إدارية إلا إذا كانت ظاهرة ومسموحة للزائر.
6. خلي الشات بوت يرفض أي سؤال خارج نطاق الموقع مثل التحفيز، شرح الدروس، الحلول، الأخبار، البرمجة، الطب، أو الأسئلة الشخصية.
7. لا تغير منطق الكود إلا لو ضروري. عدل البيانات فقط داخل EDIT_THIS_CONTENT.
```

## التركيب

1. انسخ المجلد داخل مشروع React، مثلا:

`src/components/general-chatbot`

2. ثبت الأيقونات إذا مش موجودة:

```bash
npm install lucide-react
```

3. استورد الكمبوننت في التطبيق:

```jsx
import GeneralChatbot from './components/general-chatbot/GeneralChatbot';

export default function App() {
  return (
    <>
      {/* محتوى الموقع */}
      <GeneralChatbot />
    </>
  );
}
```

ملاحظة: الشات بوت محلي بالكامل ولا يحتاج API.
